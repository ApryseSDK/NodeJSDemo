Step-by-step demo repo for getting started with Node.js and the Apryse SDK, through a three part companion blog series:

* [Creating a Document Processing App using Node.js and Express: Part 1](https://apryse.com/blog/document-processing-app-using-nodejs)
* [Creating a Document Processing App using Node.js and Express: Part 2](https://apryse.com/blog/document-processing-app-using-nodejs-part2)
* [Creating a Document Processing App using Node.js and Express: Part 3](https://apryse.com/blog/document-processing-app-using-nodejs-part3)

## License key

Set your Apryse license key in the `APRYSE_LICENSE_KEY` environment variable before starting the server:

```powershell
$env:APRYSE_LICENSE_KEY = "your-key"
npm start
```

```bash
APRYSE_LICENSE_KEY=your-key npm start
```
